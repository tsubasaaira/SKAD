# Avatar Creator Upgrade

This version replaces the emoji-based avatar preview with a layered vector illustration (SVG).
Students can customise skin tone, hairstyle, hair colour, clothing type (T-shirt, hoodie, dress,
jacket, uniform), clothing colour, and accessories. The preview updates immediately and the
existing save-avatar flow is retained.

The avatar is illustrated artwork rather than a photographic/3D character. It is designed to
work without external image assets or paid avatar APIs.
