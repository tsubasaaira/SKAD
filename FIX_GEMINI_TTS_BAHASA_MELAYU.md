# Gemini TTS Bahasa Melayu

- Browser speechSynthesis dibuang untuk mod TTS.
- TTS dijana server-side melalui Gemini Interactions API.
- Model default: gemini-3.8-flash-lite-tts.
- Output unary: WAV 24 kHz.
- Bahasa input dikesan automatik; kandungan aplikasi menggunakan Bahasa Melayu Malaysia.
- Rakaman suara guru masih tersedia sebagai pilihan alternatif.
- Secret GEMINI_API_KEY sedia ada digunakan semula.
- Optional runtime variable: GEMINI_TTS_MODEL.
